# 摆锤效应

一部关于亲子关系的无声科普短片：16:9、30fps、约 100 秒，用 Remotion 制作。片中没有配音和音乐，导出时也不带音轨。

片中所有元素都由 SVG 和 Canvas 绘制，没有用任何照片或外部素材。唯一的外部资源是 Noto Serif SC 字体，它通过 `@fontsource` 打包进项目，渲染时不需要联网。

当前阶段：**风格预览**。代表帧见 [`preview/`](preview/)，总览图是 [`preview/00_总览.jpg`](preview/00_总览.jpg)。

## 常用命令

```bash
npm install
npm run studio                 # 打开 Remotion Studio 逐帧预览，时间线上标好了 9 个镜头
npm run stills                 # 渲染 preview 用的代表帧 → out/stills/
node scripts/render-stills.mjs 12.5 61   # 渲染任意时刻（秒）的静帧
npm run render                 # 导出整片 → out/摆锤效应.mp4（--muted，不带音轨）
```

如果环境里无法联网下载 Chrome Headless Shell，可以用环境变量指定本机浏览器，例如：
`REMOTION_BROWSER=/path/to/headless_shell npm run stills`

## 调节奏：只改 `src/timeline.ts`

- `S1` 到 `S9`：每个镜头的起止时间、字幕、字幕起点，以及镜头内各个事件的参数，例如震屏幅度、摆幅、粒子溶解时刻、四只手的方向和推完后的摆幅。
- `PENDULUM`：摆长、摆球半径、周期 `period`（小角度周期 3 秒，摆幅越大周期按真实单摆公式自动变长）、开场摆幅。
- `CAMERA`：长镜头的关键帧。每个关键帧表示在时刻 t，世界中的某一点位于屏幕的某个位置，缩放是多少；相邻关键帧之间用缓入缓出插值。
- `SUBTITLE_STYLE`：逐字间隔 2 帧、全部出现后至少停留 2.5 秒、超过 20 字（不计标点）自动在标点处拆段。

**和摆锤相关的事件不写死时刻。** “吼”的浮现与震屏、“补偿”的浮现、手推摆球、牛顿摆的碰撞，在配置里写的都是“不早于某时刻”，具体落在哪一帧由物理模拟算出摆球真正到达端点或经过该位置的那一刻决定。所以改了周期或摆幅，画面事件仍然和摆球严格同步。

## 结构

```
src/timeline.ts          所有时间与参数常量
src/sim/physics.ts       摆锤物理：主摆锤、社会的大摆锤、牛顿摆碰撞、孩子的摆锤（加载时一次算完，逐帧查表）
src/sim/camera.ts        长镜头推拉、震屏
src/sim/subtitles.ts     字幕拆段与排程
src/shots/Shot01…09      每个镜头一个组件
src/scenes/              跨镜头延续的元素（两端的词、标题、粒子、手、大摆锤、牛顿摆）
src/components/          摆球、金字、手、字幕、颗粒、暗角
src/Film.tsx             全片合成
```

同一时刻只由一个镜头组件负责渲染。跨镜头延续的元素（比如“吼”从镜头 1 一直留到镜头 5）都按全片时间计算，所以镜头之间没有硬切。

## 物理与实现要点

- **主摆锤**：θ(t) = A(t)·sin φ(t)。相位按真实单摆的角频率积分，到端点减速、过中点加速。摆幅只通过两种方式改变：一是在相平面里施加一段平滑的推力冲量（推力大小按目标摆幅精确解出），二是缓入缓出的伺服调节。摆幅从不突变。
- **拖尾**：10 个逐渐变小、变淡的残影。镜头 2 中拖尾变柔和、偏暖；镜头 6 中每多一只手，拖尾就变长变亮一级。
- **镜头 6**：四只手都在摆球向左摆、也就是“推向严厉”的那半程推它，所以每只手要等摆球摆到相应位置才推。实际间隔约 2.5 到 3.5 秒，由每只手的 `at` 控制。
- **镜头 7**：家长的摆锤通过相位耦合逐渐锁定到大摆锤的相位，大约 70 秒时完全同步。
- **镜头 8 和 9**：三颗球是相贴的牛顿摆，冲击会穿过中间那颗球传过去，中间留 0.12 秒的“咔嗒”间隔，让先后顺序看得清。冲击会自然地来回传递。88 秒之后，从上方传来的第一次冲击（模拟结果约在 88.97 秒）被家长吸收：之后家长回摆碰到父母，只会自己停下，不再往上传。孩子挂在家长下方一个独立的小支点上，不和家长相连。

# 音频文件放这里

把音频按下面的文件名放进本文件夹即可，**不用改代码**。缺哪个文件就自动跳过哪个，没有任何音频时片子也能正常渲染（成片无声）。
想换文件名或调音量，改 `src/data.ts` 里的 `AUDIO`。

| 文件名 | 用途 |
|---|---|
| `bgm.mp3` | 背景音乐（全片一条轨，短于 2:36 会自动循环） |
| `sfx_hum.mp3` | 第一场 金线划出时一声细长的「嗡」 |
| `sfx_tick.mp3` | 第二场 时钟滴答（单声，代码按时间点逐渐加速触发） |
| `sfx_hit.mp3` | 第三场 柱子落定、第七场 排行榜停住的重拍 |
| `sfx_glass.mp3` | 第四场 金线冲破时的玻璃碎裂 |
| `sfx_ding.mp3` | 第五场 每段圆环亮起的清脆金属音（代码里每次略微变调） |
| `sfx_chime.mp3` | 第六场 光点落下的细碎铃声（单声，代码按随机间隔多次触发） |
| `sfx_heartbeat.mp3` | 第八场 问号闪烁时的轻微心跳 |
